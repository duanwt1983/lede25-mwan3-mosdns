新站接入流程

  1. 在门户 站点登记 页添加站点 ID 与中心端口（自动同步 Nginx）。
  2. 公网入口 LEDE 将 WAN 18443、18007 转发至 192.168.6.251。
  3. 刷 9.1 固件后打开 系统 → 管理权 → 远程管理 → 区域接入中心：中心地址 center.example.com、端口 18007、Token 在「站点登记」页顶部复制，并填本页登记的站点 ID 与 LuCI 端口；不要同时开启「本机外网管理」10443。
  4. 保存并应用后，本页站点卡片应显示「隧道在线」，点击「打开 LuCI」经 /home/gw/<site_id>/ 访问（无需单独开放 190xx 到公网）。

LuCI 访问方式

推荐（走 18443 反代）：

https://center.example.com:18443/home/gw/<site_id>/

会先进入 /home/gw/<站点ID>/cgi-bin/luci/（门店 LuCI 登录页）。若看到区域接入中心门户而非 LuCI，说明未走网关入口（勿直接打开 /cgi-bin/luci/ 或漏写末尾 /）。Authelia 是中心统一登录，通过后下一屏才是门店路由器 LuCI。

调试（需在中心机或内网放行对应 TCP 端口）：

https://center.example.com:<luci_port>/

内网隧道访问

隧道是 TCP 直通（不是 LuCI 的 18443 反代）。须同时满足：

  1. 9.1 网关「内网 TCP 隧道」：内网 IP = 门店设备（如 192.168.9.100），内网端口 = 设备真实端口；勿填 6.251 / 127.0.0.1（否则会 400/宝塔页）。保存并应用。
  2. 中心机内网可测：http://192.168.6.251:<中心端口>/（应看到门店设备，不是中心 Nginx）。
  3. 外网/手机：在公网入口 LEDE 增加 WAN:<中心端口> → 192.168.6.251:<同端口>（仅 18443 不够）。
http://center.example.com:<隧道中心端口>/

内网是 HTTPS（443）时在登记「内网备忘」写 IP:443，用门户上的 HTTPS 按钮；非 Web 服务用客户端连 center.example.com:端口。

frpc 代理命名

固件自动创建 <site_id>-luci、可选 <site_id>-ssh，以及在「内网 TCP 隧道」中登记的 <site_id>-<代理名>。门户据此显示 LuCI / 内网隧道在线状态。

维护（一般无需 SSH）

站点增删改均在「站点登记」完成。若需排查，在 6.251 上可执行 center-portal-status、systemctl status center-portal-admin frps authelia。
