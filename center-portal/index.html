接入文档

新站接入流程

  1. 公网入口 LEDE 将 WAN 18443、18007 转发至 192.168.6.251。
  2. 门店网关打开 系统 → 远程管理 → 区域接入中心：导入中心 CA，填写 站点 ID、frps Token（与站点登记页顶部一致）、LuCI/SSH 中心端口；内网 TCP 隧道在网关添加即可。
  3. 保存并应用 后网关会用 CA + Token 自动向中心登记站点与隧道（一般无需在「站点登记」重复录入）。
  4. 本页应显示「隧道在线」；LuCI 经 /home/gw/<site_id>/ 打开（无需单独开放 190xx 到公网）。

LuCI 访问方式

推荐（走 18443 反代）：

https://center.example.com:18443/home/gw/<site_id>/

会先进入 /home/gw/<站点ID>/cgi-bin/luci/（门店 LuCI 登录页）。若看到区域接入中心门户而非 LuCI，说明未走网关入口（勿直接打开 /cgi-bin/luci/ 或漏写末尾 /）。Authelia 是中心统一登录，通过后下一屏才是门店路由器 LuCI。

调试（需在中心机或内网放行对应 TCP 端口）：

https://center.example.com:<luci_port>/

内网隧道访问

隧道是 TCP 直通（不是 LuCI 的 18443 反代）。在网关「内网 TCP 隧道」填门店 LAN 设备 IP/端口（勿填 6.251 / 127.0.0.1），保存并应用。

门户上的访问链接指向中心机 LAN 地址（见页头 portal-center-lan-host，如 192.168.6.251:<中心端口>），需与中心同网段或 VPN 可达。备忘含 :443 时用 HTTPS 按钮。

frpc 代理命名

固件自动创建 <site_id>-luci、可选 <site_id>-ssh，以及在「内网 TCP 隧道」中登记的 <site_id>-<代理名>。门户据此显示 LuCI / 内网隧道在线状态。

维护（一般无需 SSH）

「站点登记」用于查看/微调自动同步的站点，或预分配端口；网关 apply 会覆盖该站的 LuCI/SSH/内网隧道列表。排查：center-portal-status、systemctl status center-portal-admin frps。
